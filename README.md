# 🤖 Automation with Python Scripts

A simple Python automation project that helps automate repetitive real-life tasks using Python.

This project automatically moves all `.jpg` image files from one folder to another using Python file handling modules.

---

# 📌 Features

- Automatically detects `.jpg` files
- Moves files to another folder
- Creates folders automatically if missing
- Beginner-friendly project
- Uses Python automation concepts

---

# 🛠 Technologies Used

- Python 3
- os module
- shutil module
- File Handling

---

# 📂 Project Structure

```text
automation-with-python-scripts/
│
├── main.py
├── source_images/
├── moved_images/
```

---

# ▶ How to Run

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/automation-with-python-scripts.git
```

---

## 2️⃣ Open Project Folder

```bash
cd automation-with-python-scripts
```

---

## 3️⃣ Add JPG Files

Put image files inside:

```text
source_images
```

Example:

```text
photo.jpg
nature.jpg
```

---

## 4️⃣ Run the Script

```bash
python main.py
```
